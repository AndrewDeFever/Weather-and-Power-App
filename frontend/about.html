Weather & Power

Weather & Power is a serverless situational-awareness application that brings current weather, time-aware forecast maps, hazard context, and public utility-outage information into one operational view. The goal is to make several independent public data sources easier to interpret together around a selected location.

What it explores

Real-world operational decisions often depend on data from systems that were never designed to work together. This project explores how to normalize those differences, keep the user experience coherent, and degrade gracefully when one upstream source is slow or unavailable.

What the app does

  • Shows current weather and a next-24-hours outlook.
  • Provides time-aware forecast layers for weather, temperature, precipitation, wind, and hazards.
  • Separates current alert context from longer-duration forecast hazards.
  • Normalizes public utility-outage information into a consistent power-status view.

Public and synthetic by design

This is a personal/public portfolio project. Committed site records are synthetic demonstration locations. They are not operational facilities, and the repository is intentionally designed to avoid publishing internal infrastructure, private addresses, contact information, or organization-specific data.

How it is built

The browser is served through CloudFront with static assets in Amazon S3. API requests route through the same public hostname to API Gateway and a FastAPI application running on AWS Lambda. The backend validates requests, normalizes provider responses, applies timeouts and fallback behavior, and limits outbound destinations.

Data sources

Weather observations, forecasts, alerts, and forecast-map products come from public U.S. weather services. Utility outage context comes from publicly accessible utility-provider sources when available. Base-map imagery is provided by Esri. Availability and restoration estimates remain subject to the underlying public providers.

Engineering focus

The project emphasizes integration engineering more than dashboard decoration: heterogeneous provider normalization, bounded external calls, partial-failure handling, time-aware GIS visualization, serverless AWS delivery, publication-safe demo data, and a deployment pipeline using GitHub Actions with AWS OIDC.
