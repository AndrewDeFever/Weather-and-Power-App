Weather & Power

A situational-awareness dashboard that brings current weather, time-aware forecast maps, hazard context, and public utility outage information into one operational view.

What it explores

External weather and utility systems do not speak the same language. This project explores how to normalize those differences, present the most useful signals together, and degrade gracefully when an upstream source is slow or unavailable.

What the dashboard does

  • Shows current conditions and a next-24-hours weather outlook.
  • Provides forecast layers for weather, temperature, precipitation, wind, and hazards.
  • Separates current alert context from longer-duration forecast hazards.
  • Combines weather context with nearby public utility outage information.

How it works

The browser loads a static interface through Amazon's content-delivery network. Application requests go to a serverless Python API, which validates input, gathers public weather and utility information, normalizes provider differences, and returns one consistent response.

Public-safe demonstration data

The committed site records are synthetic portfolio locations. They preserve realistic application behavior without publishing private facilities, addresses, contact details, or internal operational data.

Data and attribution

Public sources, product-focused presentation

Weather information is derived from public U.S. weather services. Outage information comes from publicly available utility-provider systems when those providers make data available. Map imagery is provided by Esri. Source systems can change independently, so individual integrations may require maintenance over time.

Engineering

Source and implementation

The project is built with a static JavaScript frontend, Leaflet for mapping, FastAPI for the backend contract, and a serverless Amazon Web Services deployment. Production releases are manually triggered after validation.
