About the project

Weather & Power

A serverless situational-awareness application that combines current weather, time-aware forecast maps, hazard context, and public utility-outage information around a selected location.

Why it exists

Weather and utility systems expose different data formats, timing models, and failure modes. Weather & Power brings those signals into one consistent operational view instead of making the user interpret each source separately.

What it does

  • Shows current conditions and a next-24-hours outlook.
  • Provides time-aware weather, temperature, precipitation, wind, and hazard layers.
  • Combines current alerts with longer-duration forecast hazard context.
  • Normalizes public utility outage data into one power-status experience.

How it works

CloudFront serves the static frontend and routes application requests to API Gateway and a FastAPI application on AWS Lambda. The backend validates input, normalizes provider responses, bounds external calls, and degrades individual data sources without collapsing the whole view.

Data sources

Weather information comes from public U.S. weather services. Outage context comes from public utility-provider systems when available, and map imagery is provided by Esri. Provider availability and restoration estimates remain subject to the underlying public source.

Portfolio implementation

Engineering focus

The project emphasizes integration engineering: heterogeneous provider normalization, partial-failure handling, time-aware GIS visualization, serverless AWS delivery, synthetic demonstration locations, and a GitHub Actions deployment pipeline using AWS OIDC.
